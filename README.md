# BotTeam — ทีมพนักงาน AI ที่ทำงานอยู่ในคอมพิวเตอร์ของคุณเอง

BotTeam คือแอปบน Windows ที่ให้คุณมี **"ทีมบอท AI"** ทำงานเหมือนพนักงานในบริษัท เช่น CEO ฝ่ายขาย ฝ่ายบัญชี ฝ่ายจัดซื้อ
คุณสั่งงานเป็นภาษาไทยผ่านแชทหรือพูดใส่ไมค์ บอทแต่ละตัวมี **คอมพิวเตอร์ Linux ของตัวเอง** มีหน้าจอ เมาส์ คีย์บอร์ด และเว็บเบราว์เซอร์
จึงเปิดเว็บ อ่านไฟล์ เขียนรายงาน และส่งงานต่อให้เพื่อนร่วมทีมได้เอง

- 🖥 **ทำงานในเครื่องทั้งหมด** — สมองของบอทคือโมเดล Gemma 4 ที่รันบนการ์ดจอของเครื่องเอง ข้อมูลไม่ออกนอกเครื่อง (มีโหมด DeepSeek บนคลาวด์ให้เลือกเพิ่มถ้าอยากได้ความเร็ว)
- 🙋 **คนเป็นคนตัดสินใจ** — งานสำคัญ เช่น ออกใบแจ้งหนี้ ส่งอีเมล ซื้อของ บอทต้องขออนุญาตก่อนทุกครั้ง (ตั้งได้เอง)
- 🧪 **เป็นระบบสาธิต (demo)** — ข้อมูลบริษัท ลูกค้า และตัวเลขบัญชีในตัวอย่างเป็น**ข้อมูลสมมติทั้งหมด** ห้ามต่อกับระบบจริงหรือข้อมูลลูกค้าจริง

> สร้างบน [Rakazo](https://github.com/elie222/rakazo) v0.1.6 (ระบบจัดการบอท AI แบบ open source) + แอปหน้าบ้านที่เขียนเพิ่มเป็นภาษาไทยทั้งหมด

## ทำอะไรได้บ้าง

### 1. คุยและสั่งงานบอทเป็นภาษาไทย
- แชทกับบอททีละตัว หรือคุยในห้องประชุมที่มีหลายบอท (พิมพ์ `@ชื่อบอท` เพื่อเรียก)
- **แนบไฟล์** ได้ (รูป PDF txt md csv json สูงสุด 10 MB) — บอทดูรูปได้ อ่านไฟล์ได้
- **พูดสั่งงาน** 🎤 กดไมค์แล้วพูดไทย ระบบแปลงเสียงเป็นข้อความในเครื่อง (Whisper) แล้วส่งให้บอทเอง และ**อ่านคำตอบออกเสียง** 🔊 ให้ฟัง
- เห็นทุกขั้นตอนที่บอททำ (เปิดเว็บอะไร ใช้เครื่องมืออะไร) กด Stop หยุดได้ทุกเมื่อ
- ค้นหาข้อความ/ไฟล์ย้อนหลังจากทุกแชทได้ (รองรับภาษาไทย)

### 2. บอทมีคอมพิวเตอร์ของตัวเอง
- เปิดดู **หน้าจอสดของบอท** ได้ตลอด ว่ากำลังคลิกอะไร พิมพ์อะไร
- ถ้าบอทติด เช่น เจอ CAPTCHA หรือต้องล็อกอิน บอทจะ**ขอให้คนช่วย** — คุณกด "ช่วยบนหน้าจอ" ทำเองให้เสร็จ แล้วกด "ให้บอททำต่อ"
- ปุ่ม **Terminal** เปิดหน้าต่างคำสั่งของ Linux ในเครื่องบอทได้ (ใช้ดูไฟล์หรือแก้ปัญหา)
- เครื่องของบอท**เปิดค้างตลอด** ไม่ดับเองตอนว่าง เหมาะกับงานที่ต้องรันต่อเนื่อง

### 3. ห้องควบคุม (Mission Control)
- เห็น**จอของบอททุกตัวพร้อมกัน** บนหน้าเดียว (9 ตัว = ตาราง 3×3) พร้อมสถานะว่าใครกำลังทำงาน ใครรอคุณ
- เวลาบอทส่งงานให้กัน จะมี**ลูกศร 📨 วิ่งจากผู้ส่งไปผู้รับ** ให้เห็นการทำงานเป็นทีมแบบสด ๆ

### 4. ศูนย์งาน — ที่รวมทุกเรื่องของทีม
| แท็บ | ใช้ทำอะไร |
|---|---|
| รอคุณ | คำขออนุญาตและคำถามจากบอททุกตัวรวมไว้ที่เดียว ตอบได้ทันที |
| กิจกรรม | งานที่กำลังทำและงานล่าสุดของทุกบอท |
| ทีมงาน | กระดานการมอบหมายงาน ใครส่งงานให้ใคร สถานะถึงไหนแล้ว + ช่องสั่งงานใหญ่ให้ CEO แตกงานต่อ |
| งานประจำ | ตั้งเวลาให้บอททำงานซ้ำ เช่น "สรุปยอดขายทุกเช้า 8 โมง" (เวลาไทย) |
| ทักษะ | งานที่สอนบอทไว้ (ดูข้อ 6) กดรันซ้ำได้ |
| ความรู้บริษัท | ข้อมูลที่บอททุกตัวต้องรู้ เช่น ธุรกิจ สินค้า น้ำเสียงแบรนด์ คำถามที่พบบ่อย นโยบาย — นำเข้าจากไฟล์ได้ |
| ความจำ | สิ่งที่บอทแต่ละตัวจำไว้เอง ดู แก้ หรือสั่งลืมได้ |
| ผลงาน | ไฟล์ที่บอทสร้าง เปิดดูและบันทึกลงเครื่องได้ |
| ค่าใช้จ่าย | ใช้ไปกี่ token แยกรายบอท (โหมดในเครื่องไม่เสียเงิน โหมด DeepSeek คิดเป็นเงินให้) |
| กฎอนุมัติ | ตั้งว่าเครื่องมือไหน "ต้องขออนุญาต" หรือ "อนุญาตเสมอ" มีชุดแนะนำให้กดครั้งเดียว |
| สำรองข้อมูล | สำรองทั้งระบบ ส่งออกข้อมูลบริษัทเป็น JSON และส่งออกประวัติการทำงาน (audit) เป็น CSV เปิดใน Excel ได้ |

### 5. ทำงานเป็นทีม
- สั่งงานใหญ่ให้ **CEO** เช่น "เตรียมแผนเปิดตัวสินค้าใหม่" → CEO **แตกงานส่งให้ฝ่ายที่เกี่ยวข้อง** รอผล แล้วสรุปกลับมาให้คุณ
- บอท**ตั้งนัดติดตามงานเอง**ได้ (เช่น "อีก 1 ชั่วโมงกลับมาเช็คว่าฝ่ายขายส่งรายงานหรือยัง")
- มีบอทพร้อมใช้ 9 ตำแหน่ง: CEO, ฝ่ายจัดซื้อ, ฝ่ายขาย, ฝ่ายการตลาด, ฝ่ายบริการลูกค้า, ฝ่ายบัญชี, ฝ่ายบุคคล, ฝ่ายคลังสินค้า, ฝ่ายไอที + ห้องประชุม 2 ห้อง

### 6. สอนงานด้วยการ "ทำให้ดู"
- กด 🎓 **สอนงาน** → ทำงานให้ดูบนจอของบอท (คลิก พิมพ์ เลื่อนหน้า) → กดจบ
- ระบบแปลงสิ่งที่ทำเป็น**ขั้นตอนเป็นข้อ ๆ** ให้ตรวจแก้ก่อนบันทึกเป็น "ทักษะ"
- ครั้งต่อไปสั่งแค่ "ทำ <ชื่อทักษะ>" บอทก็ทำตามขั้นตอนนั้นเอง

### 7. ระบบบัญชีสาธิต (ข้อมูลสมมติ)
- บริษัทตัวอย่าง "บริษัท สาธิตการค้า จำกัด" มีสินค้า ลูกค้า ผู้ขาย ใบแจ้งหนี้ ให้บอทฝ่ายบัญชี/ขาย/จัดซื้อ/คลัง/CEO ใช้งานผ่านมาตรฐาน **MCP**
- ถามได้ เช่น "ลูกหนี้ค้างชำระรวมเท่าไหร่" "ยอดขายเดือนนี้" "งบทดลอง" หรือสั่ง "ออกใบแจ้งหนี้ให้ลูกค้า C-004"
- ทำตามหลักบัญชี: เงินเก็บเป็นสตางค์ (ไม่มีทศนิยมเพี้ยน) VAT 7% ปัดเศษชัดเจน บันทึกบัญชีคู่ (เดบิต = เครดิต) แบบเพิ่มอย่างเดียว ส่งคำสั่งซ้ำไม่บันทึกซ้ำ

### 8. ปลอดภัยไว้ก่อน
- การ์ด **"ขออนุญาต"** โผล่ในแชท: อนุญาตครั้งนี้ / อนุญาตเสมอ / ปฏิเสธ — กดปฏิเสธแล้วบอทไม่ทำจริง
- **แจ้งเตือน Windows** เมื่อบอทรอคุณ แม้แอปย่ออยู่ คลิกแจ้งเตือนแล้วเด้งไปที่แชทนั้นเลย
- บอทอยู่ในคอนเทนเนอร์แยก **เข้าเครื่อง Windows ไม่ได้** และถูกกันไม่ให้เข้าเครือข่ายภายใน (LAN)
- ทุกบริการเปิดแค่ `127.0.0.1` (เข้าได้จากเครื่องนี้เท่านั้น)

### 9. ออฟฟิศ 3D
- เปิดเว็บ `http://127.0.0.1:3300` เห็นบอทเป็นตัวการ์ตูน**เดินไปมาในออฟฟิศ** ตามสถานะจริง (ทำงาน / ว่าง / รออนุมัติ / ประชุม)
- แสงและท้องฟ้าเปลี่ยนตามเวลาจริงของกรุงเทพฯ กล้องซูมตามบอทที่กำลังทำงาน บอทพูดไทยออกเสียงได้
- สั่งงานบอทจากในออฟฟิศได้ และมีของเล่น: คลิกพื้นเพื่อโยนบอล หรือกด "ฝนบอล" 😄
- สลับธีมมืด/สว่างได้ที่ไอคอนมุมการ์ด "ออฟฟิศบอท" (ค่าเริ่มต้นตาม Windows)

### 10. ดูแลเครื่องให้
- แถบ Monitor แสดงการ์ดจอ หน่วยความจำ ความเร็วโมเดล และจำนวนงานที่กำลังคิด/รอคิว
- ถ้าโมเดลค้าง แอป**รีสตาร์ตให้อัตโนมัติ**
- สลับสมองบอทได้ปุ่มเดียว: 🖥 ในเครื่อง (Gemma) ↔ ⚡ DeepSeek (คลาวด์ เร็วกว่า แต่ข้อมูลออกนอกเครื่อง)

### 11. ผู้ช่วยผู้บริหาร
- **สรุปงานตอนเช้า:** ตั้งเวลาทุกวัน หรือกด "สรุปตอนนี้" → CEO ดึงลูกหนี้/ยอดขายจากระบบบัญชี + งานที่รอ แล้วสรุปไม่เกิน 12 บรรทัด (📊 ตัวเลข ⚡ เรื่องต้องตัดสินใจ 👥 งานทีม ✅ แนะนำวันนี้) อ่านออกเสียงได้
- **การ์ดตัดสินใจรวม:** มีหลายเรื่องรอพร้อมกัน → ผู้ช่วยสรุปทุกเรื่องในการ์ดเดียว พร้อมแนะนำ อนุญาต/ปฏิเสธ/ตอบเอง กด "ทำตามคำแนะนำ" ทีเดียว (ยืนยันก่อนเสมอ) และแจ้งเตือนรวมเป็นอันเดียว "N เรื่องรอคุณ"
- **พูดแผนยาว ๆ แล้วแตกเป็นงาน:** ศูนย์งาน → ทีมงาน → 🎤 พูดแบบไม่ต้องเรียบเรียง → การ์ดแผนแก้ได้ (งาน ฝ่าย กำหนดส่ง ทำซ้ำ) → อนุมัติ: งานครั้งเดียว CEO แจกให้ฝ่ายต่าง ๆ งานซ้ำกลายเป็นงานประจำ
- **ตรวจข้อเท็จจริง:** กด 🔎 ใต้คำตอบบอท → บอทอีกตัวตรวจกับระบบบัญชีและความรู้บริษัท ขึ้นป้าย ✅ ถูกต้อง / ❌ ไม่ถูกต้อง / ❓ ตรวจไม่ได้ กดดูหลักฐานได้
- **ทริกเกอร์:** มีใบแจ้งหนี้ใหม่ / รับชำระ / ซื้อสินค้าเข้า หรือวางไฟล์ในโฟลเดอร์ `D:\localai\inbox` → ปลุกบอทที่เลือกใน **โหมดเฝ้าดู** (อ่านและตรวจได้ แต่ห้ามสร้าง/แก้/ส่งอะไรเอง)
- **สตูดิโอตัวตน:** ตั้งอีโมจิ สี ตำแหน่ง บุคลิก และเสียงพูดของบอทแต่ละตัว + ดาวน์โหลดการ์ดแนะนำบอทเป็นรูป PNG
- **คำติกลายเป็นกฎ:** พิมพ์ "ต่อไป…ให้ถามก่อน" แอปเสนอปุ่ม "ตั้งกฎ" ให้ทันที และปุ่ม "อนุญาตเสมอ" จะถามยืนยันก่อนทุกครั้ง

### 12. ธีมมืด / สว่าง
- ปุ่ม 🖥 ระบบ / ☀️ สว่าง / 🌙 มืด ที่แถบซ้ายล่าง — "ระบบ" เปลี่ยนตาม Windows อัตโนมัติ แถบหัวหน้าต่างและการ์ดบอทเปลี่ยนตามด้วย

## ตัวอย่างการใช้งาน

1. **สั่งงานทีม:** ศูนย์งาน → ทีมงาน → พิมพ์ "สรุปลูกค้าที่ค้างชำระ แล้วร่างอีเมลทวงถามอย่างสุภาพ" → CEO ส่งงานให้ฝ่ายบัญชีดึงตัวเลข และฝ่ายบริการลูกค้าร่างอีเมล → คุณได้สรุปกลับมา (การส่งอีเมลจริงต้องผ่านการอนุญาต)
2. **ถามด้วยเสียง:** กด 🎤 แล้วพูด "ยอดขายเดือนนี้เท่าไหร่" → บอทฝ่ายขายดึงจากระบบบัญชีสาธิต → อ่านคำตอบให้ฟัง
3. **ให้บอทอ่านเอกสาร:** แนบไฟล์ใบเสนอราคา (PDF) → "สรุปเงื่อนไขสำคัญ 5 ข้อ"
4. **งานซ้ำทุกวัน:** ตั้งงานประจำ "08:00 ฝ่ายการตลาดสรุปข่าวคู่แข่ง" → ผลรออยู่ในแชททุกเช้า
5. **เริ่มวันด้วยสรุปเช้า:** ศูนย์งาน → สรุปเช้า → ตั้ง 08:00 → ทุกเช้าได้ตัวเลขลูกหนี้ ยอดขาย และเรื่องที่ต้องตัดสินใจ
6. **พูดแผนงาน:** ทีมงาน → 🎤 "พรุ่งนี้ให้ฝ่ายขายโทรตามลูกค้าค้างชำระ แล้วทุกเช้าวันธรรมดาให้ฝ่ายบัญชีสรุปยอดขายเมื่อวาน" → ตรวจการ์ดแผน → อนุมัติ

```
     ├─ Rakazo v0.1.6   web 127.0.0.1:5173 · api 127.0.0.1:3110 · postgres · worker · supervisor
     ├─ คอมพิวเตอร์ของบอท = คอนเทนเนอร์ละตัว (มีฟอนต์ไทย)           rakazo/computer-th/

```

## ติดตั้งแบบย่อ

> โค้ดตั้งค่าที่อยู่ไว้ที่ **`D:\localai`** (ดู `Root` ใน `botadmin/Monitor.cs`, `botteam.ps1`, `botadmin/rakazo.sh`) — วางไฟล์ตามนี้ หรือแก้ path ให้ตรงเครื่องคุณ
> ขั้นตอนละเอียดและวิธีแก้ปัญหาอยู่ใน [`docs/RUNBOOK.md`](docs/RUNBOOK.md)

1. วาง `botadmin/`, `botoffice/`, `botteam.ps1`, `serve-th.bat` ไว้ใน `D:\localai\`
2. วาง llama.cpp ไว้ที่ `D:\localai\llamacpp\bin` และโมเดลไว้ที่ `D:\localai\models` แล้วสร้างไฟล์คีย์ (ดูหัวข้อ "ความลับ" ด้านล่าง)
3. ใน WSL: ติดตั้ง Rakazo v0.1.6 ที่ `~/rakazo` แล้วคัดลอก `rakazo/docker-compose.override.yml` และ `rakazo/hotfix/` ไปไว้ใน `~/rakazo/` (แอปเรียก web ที่ `127.0.0.1:5173` และ api ที่ `127.0.0.1:3110`)
4. สร้างภาพเครื่องบอทภาษาไทย: `docker build -t botteam/computer:v0.1.6-th rakazo/computer-th`
5. ติดตั้งบริการใน WSL จาก `rakazo/wsl-system/` (คัดลอก `.service` ไป `/etc/systemd/system/`, `.sh` ไป `/usr/local/sbin/` + `chmod +x` แล้ว `systemctl enable --now llama-bridge rakazo-lan-block`)
6. ระบบบัญชีสาธิต: คัดลอก `botadmin/demo-acct/server.mjs` ไป `~/rakazo/demo-acct/` แล้วสร้างไฟล์ `token`
7. Build แอป: `dotnet publish -c Release -r win-x64 --self-contained -p:PublishSingleFile=true -o dist` ในโฟลเดอร์ `botadmin`
8. ออฟฟิศ 3D: `npm ci && npm run build` ในโฟลเดอร์ `botoffice`
9. เปิดทั้งระบบ: `powershell -ExecutionPolicy Bypass -File D:\localai\botteam.ps1 start`
10. สร้างทีมบอท 9 ตัว: เปิดแอปด้วย `BotAdmin.exe --devtools-port 9223` แล้วรัน `node botadmin/seed-bots.mjs`

## 🔐 ความลับ — ไม่อยู่ใน repo นี้ ต้องสร้างเอง

repo นี้**ไม่มีคีย์ รหัสผ่าน หรือ token ใด ๆ** (ตรวจแล้วก่อนอัปโหลด) ไฟล์เหล่านี้ต้องสร้างเองในเครื่อง และ**ห้าม commit**:

| ไฟล์ | คืออะไร |
|---|---|
| `D:\localai\llm-api-key.txt` | คีย์ของ llama-server บรรทัดละคีย์ — ขึ้นต้น `gemma-` สำหรับแอป และ `rakazo-` สำหรับบอท (สุ่มยาว ๆ เอง) |
| `D:\localai\deepseek-api-key.txt` | คีย์ DeepSeek (ถ้าจะใช้โหมดคลาวด์เท่านั้น) |
| `~/rakazo/.env` (ใน WSL) | ค่าตั้งและความลับของ Rakazo สร้างตามเอกสารของ Rakazo |
| `~/rakazo/demo-acct/token` (ใน WSL) | รหัสให้บอทเรียกระบบบัญชีสาธิต — สร้างด้วย `openssl rand -hex 24 > token && chmod 600 token` |
| `%LOCALAPPDATA%\BotTeam\owner.json` | บัญชีซ่อนของแอป **สร้างให้อัตโนมัติ** ด้วยรหัสสุ่มตอนเปิดครั้งแรก |

`.gitignore` กันไฟล์เหล่านี้ไว้แล้ว แต่ก่อน push ทุกครั้งควรตรวจ `git status` อีกรอบ

## ข้อจำกัดที่ควรรู้

- โมเดลในเครื่องรับงานพร้อมกันได้ **2 งาน** งานที่เหลือต่อคิว — บอทเยอะไม่ได้แปลว่าเร็วขึ้น
- การใช้เมาส์/คีย์บอร์ดของบอทยังพลาดได้ (ทดสอบงานเว็บ 10 ข้อ สำเร็จ 5–6 ข้อ ~5 วินาทีต่อขั้น) งานสำคัญควรตรวจเอง
- Gemma บางครั้งหยุดงานกลางทาง หรือรายงานเกินจริง
- กฎอนุมัติมีผลกับ**บอททุกตัว** (Rakazo ยังไม่มีกฎรายบอท และไม่มีแบบ "ห้ามเด็ดขาด")
- ไฟล์ hotfix ใช้ได้กับ Rakazo **v0.1.6 เท่านั้น** อัปเกรดแล้วต้องทบทวน
- โหมด DeepSeek ส่งแชท ผลการทำงาน และภาพหน้าจอของบอทไปที่คลาวด์ — ใช้กับข้อมูลตัวอย่างเท่านั้น
- เครื่องบอทเปิดค้างตลอด ใช้ RAM ตลอดเวลา
- การ์ดแผนและการ์ดสรุปเรื่องรอใช้โมเดลในเครื่องเท่านั้น (โหมด DeepSeek ไม่ครอบ) · ทริกเกอร์และสรุปเช้าทำงานเฉพาะตอนเปิดแอป
